## 0. 一页结论

1. **产品定性**：`tokenhub.tencentmaas.com` = 腾讯云「大模型服务平台 TokenHub」（原 MaaS 平台
   2026-03 升级），官方声明**同时兼容 OpenAI API 与 Anthropic API 协议**（与 Spike 周双路径实测一致）。
2. **GLM 目录**：glm-5.3 / 5.2 / 5.1 / 5 / 5-turbo / 5v-turbo 六型号全部 online；
   **无 4.7 系（flash/flashx）**——GLM 家族在此 hub 没有 flash 档，低价档必须跨家族。
3. **价目**（¥/M tokens，输入/输出/缓存命中）：**GLM-5.3 = 8 / 28 / 2，与 bigmodel 官方一致，
   第三方托管零加价**；缓存命中折扣 25%。价目表**无缓存存储费列**——bigmodel「存储限免到期」
   风险不适用于 TokenHub 路径。
4. **数据条款**：TokenHub 无产品专用条款，适用《腾讯云服务协议》。第六条 6.7：
   「除双方另有约定、法律法规另有规定或执行您的服务要求所需之外，**未经您同意，腾讯云不会对
   用户业务数据进行任何未获授权的使用和披露**」——无 bigmodel 式「匿名化后训练」默认授权，
   三条款域（腾讯云/智谱国际/bigmodel）中最保守。**judge 外发切片在 TokenHub 路径条款风险最低。**
5. **「原厂直供」区分**（关键）：价目表仅 DeepSeek-V4 两个正式版标注「原厂直供」（请求转发原厂、
   原厂条款适用、峰谷计价）；**GLM 系无此标注 = 腾讯云自有算力托管**——与 Spike 周实测缓存行为
   （TTL/粒度均独立于 Z.AI 官方口径）互证。**主链路与 judge 选型避开「原厂直供」型号，
   数据即留在腾讯云条款域内。**

## 4. 数据条款判定（spec §8 残留 2 → 已闭）

- 适用文本：《腾讯云服务协议》（2025-12-23 版）第六条「用户业务数据」，TokenHub 无专用条款附加。
- 6.7：未经同意不对用户业务数据做任何未授权使用/披露；6.4：向第三方提供需事前授权；
  6.2/6.5：删除与保留期规则明确。**未见任何「匿名化后用于训练」默认授权条款**。
- 三条款域对照（judge 外发用户代码片段的风险序）：
  **腾讯云（最保守，无训练授权）< 智谱国际（API 默认不训练）< bigmodel（匿名化训练默认授权）**。
- 边界：「原厂直供」型号请求流向模型原厂，原厂条款适用——judge/主链路避开即可。
- 结论：**spec §6 的「judge 外发按保守级别对待」解除**——TokenHub 非原厂直供型号上
  judge 外发（过既有 sanitize 管线后）条款风险可接受。
